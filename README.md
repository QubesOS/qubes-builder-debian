# Qubes Builder Debian

Most of this repository is obsolete. It is the Debian/Ubuntu plugin for the
legacy [qubes-builder](https://github.com/QubesOS/qubes-builder), which is no
longer supported.

The `template_debian` and `template_ubuntu` directories are still used.
[qubes-builderv2](https://github.com/QubesOS/qubes-builderv2) runs their scripts
to build the Debian and Ubuntu templates.
